# Xiamen Air Virtual

An independent, fan-made virtual airline for flight simulation (Infinite Flight),
built around **Xiamen Air** — coastal calm, Fujian hospitality and smooth travel.
Built with Next.js 16, React 19 and Tailwind CSS v4.

> Xiamen Air Virtual is not affiliated with, endorsed by, or connected to Xiamen Air,
> the SkyTeam alliance, or Infinite Flight.

## Features

A full virtual-airline platform centred on the **Crew Center** (`/crew`):

- **Crew Center** — staff dashboard with Applications, Pilots roster, PIREP review,
  live Flights, Stats/leaderboard, LOA management, Reports and News admin.
- **Pilot hub** — file PIREPs (with one-click autofill from your IF logbook),
  flight deck, rank progression and leaderboard.
- **Public site** — home, about, staff, ranks, operations/network, news, codeshares,
  fleet explorer and a live flight map.
- **Theming** — light (default, airy) and a deep Twilight-Blue dark mode, driven
  entirely by CSS design tokens.

## Brand

| Token | Colour | Hex |

| Xiamen Blue (primary) | deep blue | `#114F9C` |
| Sky Blue (accent) | bright blue | `#18A3DE` |

Ranks follow a celestial theme — Horizon → Polaris → … → Luminary. Typeface:
Newsreader (display) + Geist (UI). The emblem is an egret over three waves,
rendered from `public/brand/xav-emblem.svg` by `scripts/make-brand-assets.mjs`.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The app runs out-of-the-box in **demo mode** with a small seeded roster. It goes
live the moment you configure the optional integrations:

- `DATABASE_URL` — Neon Postgres for pilots + PIREPs (otherwise in-memory demo store).
- `IF_API_KEY` — Infinite Flight Live API for the live map and logbook autofill.
- Discord OAuth / bot env vars for pilot login and the Discord integration
  (see `docs/egret-discord-setup.md`).

## Data

- `src/lib/data.ts` — single source of truth (brand, fleet, hubs, staff, …).
- `src/lib/routes.ts` — route network, generated by `scripts/gen-xiamen-network.mjs`.
- `src/lib/airports.ts` — airport dictionary for the network.
- `src/lib/seed.ts` — demo PIREP / pilot seed.
